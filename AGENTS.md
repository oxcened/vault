# Repository Guidelines

## Commit messages

Always use the [Conventional Commits](https://www.conventionalcommits.org/) format for commit messages:

```text
<type>[optional scope]: <description>
```

Use a concise, lowercase, imperative description. Common types include `feat`, `fix`, `refactor`, `docs`, `test`, `chore`, `build`, and `ci`.

Examples:

```text
feat: add infinite loading for stock prices
fix: stabilize cash flow query caching
refactor: simplify monthly update workflow
docs: document commit message conventions
```
